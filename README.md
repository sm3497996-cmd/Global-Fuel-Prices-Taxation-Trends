# Global Fuel Prices and Taxation Trends

## Project Overview

This project analyzes global fuel prices, crude oil prices, taxation, subsidies, and regional trends using Tableau and Flask. It provides an interactive dashboard to explore fuel-price patterns across countries and regions.

## Objectives

* Analyze petrol, diesel, and LPG prices across countries.
* Explore the relationship between fuel prices, taxation, and subsidies.
* Compare fuel-price trends across regions and income levels.
* Present insights through an interactive Tableau dashboard.
* Integrate the dashboard into a web application using Flask.

## Dataset

The dataset contains **27,468 records across 84 countries and 7 regions**, covering the period from January 2020 to April 2026.

Key fields include:

* Country and region
* Date
* Petrol price (USD/liter)
* Diesel price (USD/liter)
* LPG price (USD/liter)
* Brent crude oil price
* Income level
* Subsidy level
* Tax percentage

**Dataset file:** `global_fuel_prices_Dataset (1).csv`

## Run the Flask Application Locally

### 1. Clone the repository

```bash
git clone https://github.com/sm3497996-cmd/Global-Fuel-Prices-Taxation-Trends.git
```

### 2. Open the project folder

```bash
cd Global-Fuel-Prices-Taxation-Trends
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Start the application

```bash
python app.py
```

### 5. Open in your browser

http://127.0.0.1:5000
